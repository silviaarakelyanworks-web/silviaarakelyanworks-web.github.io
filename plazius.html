Plazius — the world's first full-cycle restaurant checkout app

Plazius offers pre-ordering, bill preview, splitting & sharing, payment, loyalty programs, and e-tips. I redesigned core user flows, conducted competitor analysis and UX testing, which increased pre-orders from 424 to 7,130 within two months.

Objective
Enhance the usability of Plazius's core features prior to integration with the SberFood app
Target Audience
Restaurant guests who pay and order via mobile
Team
PO, Art director, Product designers, Engineering Team
My role
UX/UI, copywriting, CusDev

Problem

The current design of Plazius was outdated, and the team was prepared to implement new UX patterns to test them with a small audience before integrating the main Pre-order feature into the new application.

Image placeholder

Prediction

Hypothesis for pre-order feature: If we launch the pre-order function in coffee shops across the city, our users will save time, and coffee shops will relieve cashiers and expedite the order pickup process. Consequently, cafes will integrate our service for a commission.

Image placeholder

Implementation

Competitor analysis

I conducted competitor analysis to reuse mechanics that are already familiar to users.

Image placeholder

Design

I created a design system for the updated Plazius and assisted developers in implementing these improvements.

Image placeholder

Usability testing

The Pre-ordering section underwent testing not on prototypes, but on Plazius users, and we received valuable feedback from restaurants.

Image placeholder

Design improvements

For the pre-order feature, added a description of how the service works, the option to package the order 'for dine-in', include comments, and specify a name for the cashier to expect during pickup.

Image placeholder

Results

Metrics dynamics one month after the launch of the Pre-order feature:

  • The number of establishments offering pre-orders increased from 60 to 110
  • The number of users grew from 178 to 950
  • The number of pre-orders per month rose from 424 to 7,130
  • After the design changes, user retention increased to 40%
